Установка на iPhone / iPad
  1. Нажмите кнопку ниже — скачается файл .mobileconfig
  2. iOS спросит: «Профиль загружен» → нажмите Закрыть
  3. Откройте Настройки → Профиль загружен (вверху)
  4. Нажмите Установить → введите пароль устройства
  5. Сертификат появится в Настройки → Основные → VPN и управление устройством
  6. Готово — Safari будет использовать его автоматически при верификации
⬇ Скачать профиль для iOS (.mobileconfig)
⚠ Пароль от .p12 администратор назвал вам устно при встрече. Введите его когда iOS попросит.
Установка на Android
  1. Нажмите кнопку ниже — скачается файл .p12
  2. Откройте файл из уведомления (или из папки Загрузки)
  3. Android спросит название сертификата — введите любое, например Verifier
  4. Введите пароль от .p12 (администратор сказал устно)
  5. Выберите «Для VPN и приложений» или «Wi-Fi сертификат»
  6. Chrome будет предлагать его при верификации автоматически
⬇ Скачать сертификат (.p12)
ℹ На некоторых Android нужно идти в Настройки → Безопасность → Установить сертификат и выбрать скачанный .p12 вручную.
Установка на macOS (Safari / Chrome)
  1. Нажмите кнопку ниже — скачается .p12
  2. Откройте файл — запустится Связка ключей (Keychain Access)
  3. Введите пароль от .p12 (администратор сказал устно)
  4. Сертификат появится в разделе Мои сертификаты
  5. Safari и Chrome подхватят его автоматически
⬇ Скачать сертификат (.p12)
Установка на Windows (Chrome / Edge)
  1. Нажмите кнопку ниже — скачается .p12
  2. Дважды кликните по файлу → Мастер импорта сертификатов
  3. Хранилище: «Текущий пользователь» → Далее
  4. Введите пароль от .p12
  5. Хранилище: «Автоматически» → Готово
  6. Chrome и Edge увидят сертификат автоматически
⬇ Скачать сертификат (.p12)
ℹ Firefox использует собственное хранилище. Для Firefox: Настройки → Конфиденциальность → Просмотр сертификатов → Импорт.
Google Authenticator (резервный метод)

Отсканируйте QR-код в приложении Google Authenticator, Aegis или любом другом TOTP-приложении. Это резервный способ верификации если браузер не подхватит сертификат.
